# MirrorShop

AI storefront visibility audit for Shopify merchants.

## What it does
Scrapes a Shopify storefront, runs a constrained AI visibility test,
and shows the gap between what a merchant intends and what an AI
shopping agent can actually infer.

`llms.txt` is an output artifact, not the main product.

## Stack
Node.js · Playwright · Groq · HTML/CSS/JS
